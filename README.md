\# Git Practice Project



Учебный проект по Git и CI/CD.



\## Описание



Проект содержит математические функции в `utils.py` и unit-тесты в `test\_utils.py`. CI настроен через Jenkins.



\## Функции



| Функция | Описание |

|---------|----------|

| `add(a, b)` | Сложение |

| `sub(a, b)` | Вычитание |

| `mul(a, b)` | Умножение |

| `div(a, b)` | Деление (с проверкой деления на ноль) |

| `pow(a, b)` | Возведение в степень |

| `mod(a, b)` | Остаток от деления |

| `floor\_div(a, b)` | Целочисленное деление |
